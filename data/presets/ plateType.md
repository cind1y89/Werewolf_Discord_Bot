# 狼人殺板型與規則整理

## 基礎觀念與閱讀方式

1. **預設規則：** 除板型或規則另有說明外，12 人局皆為**雙爆吞警徽**，且**女巫全程不可自救**。
2. **自爆規範：** 除板型或規則另有說明外，未特別註明限制的狼人角色皆可自爆。
3. **共通角色：** 各板型中未特別改寫的常見角色（如預言家、女巫、獵人、守衛、平民、狼人等），皆依標準規則運作；有特殊改動或額外備註者，會於該板型中列出。

## 7 人局

### 7 人官方局：生還者

* **配置：** 預言家、女巫、獵人、守衛、1 平民、1 狼人、白狼王
* **角色技能：**
* **預言家：** 神職。每晚查驗一名玩家，法官告知其為好人或狼人。
* **女巫：** 神職。擁有解藥與毒藥各一罐，每晚限用一罐，全程不可自救。
* **獵人：** 神職。出局時可開槍帶走一名玩家（中招毒藥則不可開槍）；夜間法官會告知隔夜／白天是否可開槍（無論當晚是否死亡），離場前需先向法官確認。
* **守衛：** 神職。每晚可守護一名玩家免疫狼刀（中毒仍會死亡），不可連續守護同一人，可自守，可空守。*特殊規則：同夜被守衛守護又被女巫解藥救起者，仍會死亡。*
* **狼人：** 狼隊，可自爆、入狼隊。每晚與狼隊討論擊殺目標；白天可翻牌自爆並直接進入天黑。
* **白狼王：** 狼隊，可自爆、可自刀、入狼隊。自爆時可帶走一名玩家，其他死亡方式無技能。


* **夜間順序：** 守衛 → 狼人 → 女巫 → 預言家 → 獵人 → 天亮 → 死訊

* **配置：** 熊、女巫、獵人、3 民、高級村民、1 狼、種狼

* **夜間順序：** 狼刀（種狼） → 女巫 → 預言家 → 獵人 → 天亮 → 死訊 → 高級村民
